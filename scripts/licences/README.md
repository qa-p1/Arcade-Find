Standard licence texts from the SPDX License List (github.com/spdx/license-list-data, tag v3.29.0, `text/`), used
by `scripts/notices.py` for crates that declare a licence but publish no licence file. The `<year>`/`<copyright
holders>` line is filled with the crate's authors.

`CC0-1.0.txt` is the Creative Commons legal code as shipped in Debian's `/usr/share/common-licenses/CC0-1.0` (used for
hexf-parse, which dedicates its work to the public domain and publishes no file).
